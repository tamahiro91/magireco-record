# マギレコ実戦記録

パチスロ「マギアレコード」の実戦データを記録・管理するための個人用Webアプリです。スマホのブラウザからそのまま使えます。

**アプリを開く：** https://tamahiro91.github.io/magireco-record/

## 主な機能

- 来店記録の一覧・詳細の2画面構成、ダーク配色のモバイル最適化UI
- - 店舗名・日付・台番号・メモの記録、来店回数と当選回数の集計、店舗名での検索
  - - ゲーム数・ポイント・AT初期ゲーム数、BIG/みたま/各種CZなど当選パターンの記録
    - - 設定示唆情報（ビッグ終了後のボイス・画面パターン、エンブリオ当選契機、ストーリー順番示唆など）の記録
      - - スイカ/CZ/CZ成功のタップカウンター、投資枚数の自動計算
        - - 記録のドラッグ並び替え・削除
          - - JSONエクスポート/インポート、同期コードによるデバイス間データ共有（Firebase Firestore）
           
            - ## 使い方
           
            - 上記のリンクをスマホやPCのブラウザで開くだけで利用できます。インストール不要、ログイン不要です。右下の「＋」ボタンから来店記録を追加してください。
